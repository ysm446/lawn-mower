# ui — UI の設計ガイド

作成日時: 2026-11-11 05:28
更新日時: 2026-11-13 15:26

UI は別プロジェクト weather-globe(`D:\GitHub\weather-globe`)の流儀に合わせる。新しい部品を足すときは、まず weather-globe の `src/renderer/style.css` と `index.html` に同じ役割のものがないかを見て、あればその見た目と作りに合わせる。

## 見た目

- 色はグレーだけでまとめる。選んでいるものは色ではなく明るさで見分ける。
- パネルはすりガラス(`backdrop-filter` でぼかし、後ろの明るさを落とす)。明るい芝の上でも文字が読めるようにするため。
- 色や効果は `style.css` の先頭の変数(`--panel`、`--glass`、`--line`、`--text`、`--text-2`、`--accent` など)を使い、個別に色を書かない。
- 角の丸みはパネルが 8px、ボタンが 6px。画面の端からの余白は 16px、部品どうしの間隔は 8px。
- 文字は 14px を基準にし、パネルの中は 13px、補助的な表示は 12px。数字は `tabular-nums` で桁を揃える。
- フォントは Noto Sans JP、なければ游ゴシック UI。

## 配置

| 場所 | 内容 |
| --- | --- |
| 左上(`#top-left`) | 「状態」のパネル(乗っている機体、速度、刈刃、刈った面積、勾配、標高、走行距離、経過時間)と「性能」のパネル(見出しに fps。開くとフレーム間隔、CPU の処理時間、ドローコール、ポリゴン、頂点、ジオメトリ・テクスチャ・シェーダーの数。設定の「性能を表示」で出し入れ。既定は閉じる)。「状態」と「性能」は右の列のパネルと同じく見出しを押すと開閉する。機体ごとの値は乗っている機体のもので、誰にも乗っていなければ「-」。動作確認用の法線マップ(設定の「動作確認」で出したときだけ) |
| 上中央(`#top-center`) | 操作の案内。誰にも乗っていない俯瞰では、乗り方と見る場所の動かし方。乗っているときは、その機体の名前と運転の操作。管制の視点では、選んでいる機体と、選び方・指示の出し方。自動の旋回中は、その向きと速さに変わる |
| 右上(`#top-right`) | アイコンのボタン(自動運転、やり直し、設定、操作の一覧) |
| 右の列(`#right-stack`) | 設定のパネル(マップ、カメラ、時間、光と風、区分け、区画と経路)。見出しを押すと開閉する。芝刈り機の台数と刈高は「区画と経路」に置く |
| 右下(`#bottom-right`) | 倍速のプルダウン(`#speed-box`。段が多いのでボタンを並べない)と、視点の切り替え |
| 右下の切り替えの上(`#screenshot-toast`) | スクリーンショットと録画の保存の通知。クリックで保存先を開く。6 秒で消える(weather-globe と同じ) |
| 中央のダイアログ(`#key-help`) | 操作の一覧 |
| 中央のダイアログ(`#settings`) | 設定ウインドウ。タブで分けたセクションに項目を並べる |

- パネルのない隙間は `pointer-events: none` にして、後ろの画面の操作(ドローン視点のドラッグなど)を通す。
- 設定のパネルと左上の「状態」「性能」は、閉じているときは見出しの幅まで縮める。開閉は記録して次の起動で戻す(`ui.ts` の `rememberPanelFolds`。鍵は見出しの文字、localStorage の `lawn-mower-panel-folds`)。記録が無ければ `index.html` の `open` のまま。

## 部品

`src/renderer/src/ui.ts` にまとめている。配置は `index.html`、見た目は `style.css`、値のやり取りは `ui.ts` と `main.ts` が受け持つ。

| 部品 | 関数 | 用途 |
| --- | --- | --- |
| スライダー | `addSlider` | ラベル、スライダー、値の表示の 1 行 |
| 段のあるスライダー | `stopsSlider` | 絞り、シャッター速度、ISO のように決まった段から選ぶもの |
| 切り替え | `addSwitch` | 横に並んだボタンから 1 つを選ぶ |
| 値の一覧 | `addReadout` | 項目名と値を並べた表示。変わった所だけ書き換える |
| 選択 | `addChoice` | ラベルと、横に並んだボタンから 1 つを選ぶ行(設定ウインドウ用) |
| プルダウン | `addSelect` | ラベルと、一覧から 1 つを選ぶ行(刈り方)。一覧は weather-globe の `custom-select.ts` を移植した `customSelect.ts` が出す(OS 標準の一覧は使わない)。値は保存して次の起動で戻す |
| パネルの表示ボタン | `addPanelToggle` | パネルの見出しの行に置く、目のアイコンのボタン。そのパネルが扱うもの(区分け、経路)の表示・非表示を切り替える。パネルを閉じたままでも押せる |
| チェック | `addCheck` | オンとオフを切り替える 1 行(自動露出、被写界深度) |
| 操作の一覧 | `setupHelp` | キーと説明の一覧のダイアログ |

- 各部品は「画面の値を現在の設定に合わせ直す関数」を返す。キー操作などで設定を変えたら `syncUi()` を呼ぶ。
- ボタンは押したあとフォーカスを外す。Space などの運転のキーがボタンに取られないようにするため。
- アイコンは 24px の枠に線で描いた SVG を `index.html` に直接書く(線の太さ 2、表示は 18px)。
- スライダーとチェックには、右端に「既定に戻す」ボタンが付く(`addSlider` と `addCheck` が自動で付ける)。値が既定値のときは薄く表示し、押せない。既定値は部品を作った時点の値。状況で変わるもの(視点ごとの焦点距離など)は `defaultValue` で渡す。
- 説明が必要な項目には `title` で補足をつける。
- キー操作を足したら、操作の一覧(`main.ts` の `setupHelp` に渡す内容)にも足す。
- ダイアログが開いている間に効かせたくないキー(Tab、Esc など)は、`onPress` の処理で false を返して、ブラウザの既定の動き(フォーカスの移動、ダイアログを閉じる)に任せる。

## 機体の選び方(RTS の流儀)

- 起動時は誰にも乗らず、俯瞰で全体を見る。芝刈り機をクリックすると乗り、Tab で乗り移り、Esc で降りる。
- 誰にも乗っていない俯瞰は、ドローンの視点と同じ操作にする(左ドラッグで回り込む、右ドラッグで動かす、ホイールで寄る)。クリック(ドラッグしない押し離し)は機体を選ぶのに使う。
- 自動運転のボタン(と P)は、乗っている機体に効く。管制の視点では選んでいる機体に効く。どちらもなければ全台に効く。ボタンの説明(`title`)に、対象(何号機か、全台か)を出す。

### 管制の視点

- 視点の切り替えの 4 つ目(以前の「定点」)。カメラは誰にも乗っていない俯瞰と同じ動きで、機体を追わない。
- 機体には乗らない。クリックで選び、Shift+クリックで足す・外す、Shift+左ドラッグの四角で囲んで足す。数字キーと Tab でも選ぶ。何もない所のクリックと Esc で、選ぶのをやめる。選んでもカメラは動かさない。
- F で、選んでいる機体のいる所へ見る場所を移す(`CameraRig.lookAt`)。押した時点の位置へ、カメラの向きと距離を保ったまま平行に動かす(移る間はなめらかにつなぐ)。そのあとは機体を追わない。何台か選んでいるときは、その真ん中。
- 地面の右クリックで、選んでいる機体にその場所の区画を刈らせる(`orderPlot`)。自動運転にして向かわせ、何台かなら分担する。指示された区画は刈り終えるまでほかへ移らない(`MowerUnit.ordered`)。右ドラッグは見る場所を動かす操作のまま。
- 選んでいる機体のまわりに、経路の矢印と同じ描き方の輪を出す(`render/selectionRings.ts`。半透明の帯と光る縁取り、色はその機体の経路の色、ゆっくり回る切れ目が 4 つ)。
- 乗っていた機体から管制に移ると、カメラはその場で止まり、その機体を選んだ状態になる。管制から追従やドローンに移ると、選んでいた機体に乗る。俯瞰に移るときは乗らない。

## 設定の置き場所

- 右の列のパネル: 絵作りや、その場で試しながら変えるもの(カメラ、時間、光と風、区分け、区画と経路)。太陽の向きのように、画面を見ながら動かすものはここに置く。スライダーとチェックの値は保存して次の起動で戻す(`ui.ts` の `restorePanelValues`。部品を作ると自動で登録される)。時刻のように進んでいく値や、その場の状態は `persist: false` で外す。
- 設定ウインドウ(`settings.ts`): PC の性能や好みに合わせて一度決めれば済むもの(描画の負荷、表示の有無、芝の葉と縞の強さ)。次の起動にも引き継ぐ。動作確認用の表示(法線マップ)は「動作確認」のタブに置き、次の起動には引き継がない(`TRANSIENT_KEYS`)。

## 地面に重ねて描くもの

範囲や経路など、地面に重ねて描くものも weather-globe(`src/renderer/highlights.ts`、`thick-arrow.ts`)の描き方に合わせる。部品は `src/renderer/src/render/overlay/` にある。

- 範囲は、半透明の塗りと縁取りで示す。塗りは輪郭のすぐ内側を濃く、内へ行くほど薄くする。塗りは輪郭の多角形を三角形に分けた面で描き、縁取りと同じ輪郭を使う(格子のテクスチャで塗ると、縁が階段状になり、縁取りとずれる)。
- 線は、画面の上で一定の太さを持つ帯(`Ribbon`)で描く。中心を白に寄せ、縁を色のまま薄くする。
- 向きのある道筋は、太さのある矢印(`buildThickArrow`)で描く。帯は一定の太さで、先端に幅の広い矢じりを付ける。
- 推定や補助的な道筋(刈刃を上げた移動など)は破線にする。
- 色は `OVERLAY_PALETTE`(彩度を少し落とし、明るさをそろえた色)から選ぶ。
- 経路は機体ごとに色を変える(1 号機から順に teal、gold、coral、violet、sky)。乗っているときはその機体の経路だけを、誰にも乗っていないときは全台の経路を出す。

## 画面に重ねる補助の表示

- 太陽の向きのギズモ(`sunGizmo.ts`)は、terrain-graph(`D:\GitHub\terrain-graph`)の絵に合わせる。操作している間だけ出し、やめたら薄くなって消える。
- 線の色は意味を持つ色として固定し、`style.css` の変数からは引かない(案内の線は灰、高度の弧は淡い橙、光の矢印は橙)。数字の箱は `--panel-strong` を使う。
