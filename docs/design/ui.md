# ui — UI の設計ガイド

作成日時: 2026-11-11 05:28
更新日時: 2026-11-11 11:29

UI は別プロジェクト weather-globe(`D:\GitHub\weather-globe`)の流儀に合わせる。新しい部品を足すときは、まず weather-globe の `src/renderer/style.css` と `index.html` に同じ役割のものがないかを見て、あればその見た目と作りに合わせる。

## 見た目

- 色はグレーだけでまとめる。選んでいるものは色ではなく明るさで見分ける。
- パネルはすりガラス(`backdrop-filter` でぼかし、後ろの明るさを落とす)。明るい芝の上でも文字が読めるようにするため。
- 色や効果は `style.css` の先頭の変数(`--panel`、`--glass`、`--line`、`--text`、`--text-2`、`--accent` など)を使い、個別に色を書かない。
- 角の丸みはパネルが 8px、ボタンが 6px。画面の端からの余白は 16px、部品どうしの間隔は 8px。
- 文字は 14px を基準にし、パネルの中は 13px、補助的な表示は 12px。数字は `tabular-nums` で桁を揃える。
- フォントは Noto Sans JP、なければ游ゴシック UI。

## 配置

| 場所 | 内容 |
| --- | --- |
| 左上(`#top-left`) | 状態の表示(速度、刈刃、刈った面積、勾配、標高、走行距離、経過時間)と fps |
| 上中央(`#top-center`) | 操作の案内 |
| 右上(`#top-right`) | アイコンのボタン(自動運転、やり直し、操作の一覧) |
| 右の列(`#right-stack`) | 設定のパネル(カメラ、光、芝、区分け)。見出しを押すと開閉する |
| 右下(`#bottom-right`) | 切り替え(倍速、視点) |
| 中央のダイアログ(`#key-help`) | 操作の一覧 |

- パネルのない隙間は `pointer-events: none` にして、後ろの画面の操作(ドローン視点のドラッグなど)を通す。
- 設定のパネルは、閉じているときは見出しの幅まで縮める。

## 部品

`src/renderer/src/ui.ts` にまとめている。配置は `index.html`、見た目は `style.css`、値のやり取りは `ui.ts` と `main.ts` が受け持つ。

| 部品 | 関数 | 用途 |
| --- | --- | --- |
| スライダー | `addSlider` | ラベル、スライダー、値の表示の 1 行 |
| 段のあるスライダー | `stopsSlider` | 絞り、シャッター速度、ISO のように決まった段から選ぶもの |
| 切り替え | `addSwitch` | 横に並んだボタンから 1 つを選ぶ |
| 値の一覧 | `addReadout` | 項目名と値を並べた表示。変わった所だけ書き換える |
| 操作の一覧 | `setupHelp` | キーと説明の一覧のダイアログ |

- 各部品は「画面の値を現在の設定に合わせ直す関数」を返す。キー操作などで設定を変えたら `syncUi()` を呼ぶ。
- ボタンは押したあとフォーカスを外す。Space などの運転のキーがボタンに取られないようにするため。
- アイコンは 24px の枠に線で描いた SVG を `index.html` に直接書く(線の太さ 2、表示は 18px)。
- 説明が必要な項目には `title` で補足をつける。
- キー操作を足したら、操作の一覧(`main.ts` の `setupHelp` に渡す内容)にも足す。

## weather-globe から今後取り入れる候補

- 設定のダイアログ(タブ分け、項目ごとの「既定に戻す」)。設定項目が増え、保存が必要になった段階で入れる。
- カメラのパネルの「自動露出」「被写界深度」のチェック(M5 で機能と一緒に入れる)。
- スクリーンショット保存の通知。
