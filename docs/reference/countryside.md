# 田園丘陵

作成日時: 2026-11-15 20:11
更新日時: 2026-11-15 20:11

## 目的と操作

イタリアの田園をイメージした、畑のような土地構成を持つ草地。マップ一覧から「田園丘陵」を選ぶ。起動時の指定は `map=countryside`。既定マップは従来の「丘陵」のまま。

## 構成

- `terrain.ts`: 310 m、155 m、75 m の波長を重ねた穏やかな起伏。遠景にも連続する。
- `countryside.ts`: 主道一本と横断する道三本。両端を固定し、帯状の候補を動的計画法で探索する。距離・縦断勾配・横断勾配・予定線からの距離を評価し、局所平均で格子の折れをならす。
- 道の左右関係で八つの土地 ID を決める。農道の幅は概ね 6 m、両側に畦を残す。土地はマップ生成時に固定し、勾配設定を変えても境界が変わらない。
- 土地ごとの草色と土色の道を共通テクスチャで描く。近景の草の葉も同じ情報を使い、道には葉を出さない。
- 道沿いに細身の針葉樹を配置する。幹の周囲 3 m を通行・作業から除外する。
- 到達可能な土地内を連結成分に分けて作業区画とする。25 m² 未満の切れ端は除外する。土地を越えて吸収しない。
- 農道と畦は作業から除外するが、移動では通れる。従来どおり、移動は他の草地も通れる。

## 初版の範囲と制約

- 土地配置の構図は固定。シードによって地形と道の曲がり方が変わる。所有者や土地売買・分割の履歴、境界編集は未実装。
- 道は地表へ描き、切土・盛土による造成は行わない。等高線そのものをなぞる方式ではなく、上り下りの負担を評価する近似。
- 農道を優先する移動コストや、道路だけを通る制限は未実装。短時間の走行は確認したが、全区画の刈り切りは未検証。
- 草刈りの方向は既存の共通設定を使う。土地ごとの刈り方向は未実装。
- 任意のシードで道路の勾配上限を保証しない。既定シードでは、平滑化後の道路の縦断勾配が 25% 未満であることをテストする。

## 検証

`npm run build` 成功。`npm test` は全72件成功。追加テストで土地境界の保持、道路の作業対象からの除外、八つの作業区画、既定シードの道路勾配、再現性、従来の既定マップを確認。Electron の画面保存で描画と短時間の自動走行を確認した。
