## 現在の状況

M0(土台)から M4(自動走行)までが完了。丘陵の地形を手動または仮の自動運転で走ると、刈った所が短くなり、斜面にも明暗の縞が残る。勾配から「乗用機で刈る、斜面用機で刈る、刈らない」の区分を求めて表示でき、乗用機で刈れる範囲は自動運転で刈れる。M5 は物理カメラ(自動露出、被写界深度、ミニチュア倍率、ティルト)まで入った。近景の芝の葉も入った。M6(Blender 製の芝刈り機モデル)も入った。M7 のうちタイムラプス表現(コマ落ち、時刻で動く太陽、流れる雲の影)も入った。次は M7 の残り(芝の再生長)か、M5 の残り(空と大気の作り込み)。

## 実行方法

- ふだんの起動: `start.bat`。ビルドの出力(`out/`)が無いか、`src` や設定ファイルのほうが新しいときだけ `npm run build` を走らせ、ビルド結果を起動する。要るかどうかは `tools/needs-build.mjs` が更新日時で調べる。
- 開発時の起動: `npm run dev`(`start.bat` は開発モードでは起動しない)
- ビルド(型チェックを含む): `npm run build`
- ビルド結果の起動: `npm run start`
- テスト: `npm test`
- 樹木のモデルの作り直し: `& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --python tools\blender\build_trees.py`
- 芝刈り機のモデルの作り直し: `& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --python tools\blender\build_mower.py`(`mower.glb` を上書きする。モデルを直すときはスクリプトを直して実行する)
- 動作確認用の環境変数(`src/main/index.ts`):
  - `LM_QUERY`: 起動時の指定。例 `auto=1&timescale=16&cam=orbit&ui=0&help=1&seed=7&zones=1&path=1&blades=0&zoom=0.5&map=meadow&log=1&settings=1&timelapse=1&time=17.5&clouds=0.5&orbit=3&sunel=14&sunaz=0&chase=0,-18&gizmo=1`
  - `LM_SCREENSHOT`: 指定したパスに画面を保存して終了する。
  - `LM_SCREENSHOT_DELAY`: 保存までの待ち時間(ミリ秒)。

## 注意点

- タイムラプス中のカメラは機体を遅れて追う。倍速が高いと、往復する機体の動きにカメラが追いつかず、機体が画面の外へ出ることがある(64 倍速で 20〜30 m ほど遅れる)。
- 256 倍速では 1 コマの間に機体が 70 m ほど進む。往復刈りの 1 列が 1〜2 コマで終わるので、機体は飛び飛びに見える。
- 時刻は芝に影響しない(芝は伸びない。再生長は未実装)。やり直し(R)で時刻も起動時に戻る。
- 雲は高さ 1200 m の平らな模様で、厚みや立体感はない。空に見える雲の見え方は、低い視点では確かめていない。
- 雲の影の境目はなだらか(数十 m かけて変わる)。くっきりした影にはならない。
- 太陽の光と空の明るさは、大気の計算から決まるようになった。以前の固定値(太陽 90000 lx、空 18000 lx)とは少し違う。朝 7:30 の太陽は約 8 万 lx。
- 霞の色は「その向きの地平線の空の色」で近似している。見下ろす向きでも地平線の色を使うので、高い所から見下ろすと、実際より少し明るく霞む。
- 空の表は、高さ 60 m から見上げた空で固定している(カメラの高さでは変えない)。
- 空の見え方は、地平線を見る構図(昼)で確かめた。真上を見上げる構図や、朝夕の空の全体は確かめていない。
- 夜は無い(太陽の高度は 3° まで)。太陽が地平線の下に来る場合の空は計算できるが、月や星が無いので使っていない。
- 樹木の影の地図は、太陽が動くたびに作り直される(以前からカメラが動くたびに作り直しているので、負荷は変わらない)。
- VS Code の拡張機能から起動した端末では、環境変数 `ELECTRON_RUN_AS_NODE=1` が設定されていて Electron が起動に失敗することがある。その場合は `Remove-Item Env:ELECTRON_RUN_AS_NODE` を実行してから起動する。
- 縞の強さ、芝の色、つやの強さは調整の途中。刈っていない芝のきらめきが強めで、刈った芝は控えめ。
- 刈り跡の向き(縞)は、帯の両脇で 1.5 テクセル(約 19 cm)だけ外にはみ出して書き込まれる。
- 急な旋回中は刈刃の帯の四角形がねじれ、刈り跡の端がわずかに乱れることがある。
- 芝丈は 8 bit(約 0.8 mm 刻み)で持っている。グリーンのような数 mm の刈高を扱うときは精度を上げる。
- 技術構成、マイルストーン、区分の閾値は提案どおりに進めているが、未確定。
- 既定の地形(シード値 7)は、15° を超える斜面が約 1 割、30° を超える所はほぼない。「刈らない」区分を見るには閾値を下げる。
- 刈り幅は水平に測っている。横に傾いた斜面では、地面に沿った実際の幅より数 % 狭くなる。
- 自動運転は区画を順に刈り進めるので、止めなければ全体(丘陵で約 24 ha、20 区画ほど)を刈り続ける。1 区画(約 1.2 ha)は 64 倍速で 1 分ほど。
- 区画の境目では、両側の区画がそれぞれ外周刈りをするので、境目の近くは二重に刈る。区画の境目の線は、隣どうしで別々にならして描くので、寄るとわずかにずれて二重に見える。
- やり直し(R)や、区分けの閾値・区画の広さを変えると、区画は分け直され、刈り終えた印は消える(芝の刈り跡は残る)。
- 全部の区画を刈り終えたあとで自動運転を入れ直しても、走り出さない(やり直すか、区画を選び直す)。
- クリックでの区画の選択と `[` `]` キーは、実際の操作では確かめていない。
- 「所要時間の目安」は、旋回や外周での減速を大まかな係数で見込んだ値。実際とのずれは確かめ直していない。
- ぼけの大きさには上限がある(画面の高さの 1.6%)。ミニチュア倍率を大きくしても、それ以上はぼけない。
- 刈りカスの粒のうち、裏面が見えているものは暗く(黒っぽく)写る。
- 刈りカスの粒は実物より大きい(幅 2.2 cm、長さ 4〜10 cm)。少し離れても見えるようにするため。粒は影を落とさない。
- 地面に残る刈りカスの点々は、今は消えない(芝状態マップの鮮度を使っていて、時間で減らす処理は M7 で入れる)。
- ピントは常に機体に合わせる。地面をクリックして合わせる操作はまだない。
- 真上に近い俯瞰では、画面内の距離の差が小さいので、ミニチュア倍率を上げてもあまりぼけない。
- 自動運転の旋回は、刈る範囲の外(斜面側)に少しはみ出すことがある。旋回の曲線が範囲に収まるかは確かめていない。
- 外周刈りの角と、列の端と外周の間に、小さな刈り残しが出ることがある(テストでの刈れた割合は、四角い範囲で 97% 以上、穴のある範囲で 94% 以上)。
- 外周刈りの経路は、ならした分だけ角が丸くなる(半径 2〜3 m ほど)。入り組んだ境界の細かな出入りは追わない。
- 列をつなぐ順番は「近い順」の単純な方法。入り組んだ形では、離れた列への移動が増える。
- 経路は斜面の向きを考えない。刈る向きは手で決める。
- 斜面用機の区分を刈る機種と経路は未実装(M8)。
- 機体は斜面でも速度が変わらない(重力や滑りは未実装)。
- 車輪の跡は消えない。何度も通った所は跡が重なっていく。芝の再生長(M7)と一緒に、時間で消えるようにする。
- 車輪の跡は、前輪の操舵の向きを見ていない(4 輪とも機体の向きに寝かせる)。
- 運転者は動かない(ハンドルを切っても腕と頭は動かず、ハンドルも回らない)。箱と球と丸棒を組み合わせた模型らしい作りで、顔は寄ると簡単な形と分かる。
- 芝刈り機の色や形は実在の機種に合わせていない。
- 樹木に当たり判定はない。手動で運転すると、木をすり抜ける(自動運転は避ける)。
- 樹木の葉の絵は手描き風の単純な形で、写真ではない。寄ると板であることが分かる。
- 林の地面は空き地と同じ草のまま(落ち葉や、日陰で草がまばらになる表現はない)。
- 影は 220 m より遠くには落ちない。段の境目で、影の細かさが変わるのが見えることがある。
- 影を 3 段にしてから、描画は 100〜113 fps(以前は 120 fps)。丘陵のマップでも同じくらい下がった。
- 林の中の地面も、空き地と同じ草が生えている(下草や落ち葉の表現はない)。
- 機種を切り替える画面はまだない。使う機種は `vehicle.ts` の `FAIRWAY_MOWER` で固定している。
- 刈り幅は定義から求めるようになり、3.0 m から 3.1 m に変わった(リールどうしの重なりを含む、実際に刈る幅)。経路の列の間隔もその分だけ広がる。
- 地形は影を落とさない(丘の陰は、光の当たる向きによる明暗だけ)。芝の葉も影を落とさない。
- 芝の葉は、離れて見るほど描く範囲が広がる(見ている地面までの距離に比例)。並びを「芝を描く距離」の 2 倍まで作るので、その距離を長くすると前より重くなりやすい。
- 視線が丘の稜線をかすめる所では、見ている地面までの距離そのものが急に変わるので、芝の葉の細かさも急に変わることがある。
- 芝の葉は、カメラが見ている地面のまわりにだけ出る(半径は設定の「芝を描く距離」)。その先は葉のない地面になる。
- 右の列のパネルの値(カメラ、光と風、芝、区分け、経路)と、選んだマップ・視点・倍速は保存しない。保存するのは設定ウインドウの項目だけ。
- 芝の葉は実物より太く(根元 1.8 cm)、まばら(4 cm 間隔)。模型らしさと描画の軽さのための割り切り。
