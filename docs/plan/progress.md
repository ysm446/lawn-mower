## 実行方法

- 開発時の起動: `npm run dev`
- ビルド(型チェックを含む): `npm run build`
- ビルド結果の起動: `npm run start`
- テスト: `npm test`
- 芝刈り機のモデルの作り直し: `& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --python tools\blender\build_mower.py`(`mower.glb` を上書きする。モデルを直すときはスクリプトを直して実行する)
- 動作確認用の環境変数(`src/main/index.ts`):
  - `LM_QUERY`: 起動時の指定。例 `auto=1&timescale=16&cam=orbit&ui=0&help=1&seed=7&zones=1&path=1&blades=0&zoom=0.5`
  - `LM_SCREENSHOT`: 指定したパスに画面を保存して終了する。
  - `LM_SCREENSHOT_DELAY`: 保存までの待ち時間(ミリ秒)。

## 注意点

- VS Code の拡張機能から起動した端末では、環境変数 `ELECTRON_RUN_AS_NODE=1` が設定されていて Electron が起動に失敗することがある。その場合は `Remove-Item Env:ELECTRON_RUN_AS_NODE` を実行してから起動する。
- 縞の強さ、芝の色、つやの強さは調整の途中。刈っていない芝のきらめきが強めで、刈った芝は控えめ。
- 刈り跡の向き(縞)は、帯の両脇で 1.5 テクセル(約 19 cm)だけ外にはみ出して書き込まれる。
- 急な旋回中は刈刃の帯の四角形がねじれ、刈り跡の端がわずかに乱れることがある。
- 芝丈は 8 bit(約 0.8 mm 刻み)で持っている。グリーンのような数 mm の刈高を扱うときは精度を上げる。
- 技術構成、マイルストーン、区分の閾値は提案どおりに進めているが、未確定。
- 既定の地形(シード値 7)は、15° を超える斜面が約 1 割、30° を超える所はほぼない。「刈らない」区分を見るには閾値を下げる。
- 刈り幅は水平に測っている。横に傾いた斜面では、地面に沿った実際の幅より数 % 狭くなる。
- 自動運転で刈る範囲は、既定では出発点を中心とする 120 m 四方(約 1.1 ha)に絞っている(「経路」パネルの「刈る範囲」)。64 倍速で 45 秒ほどで刈り終わる。全体(約 24 ha)にすると、64 倍速でも 10 分以上かかる。
- 「所要時間の目安」は、旋回や外周での減速を大まかな係数で見込んだ値。実際とのずれは確かめ直していない。
- ぼけの大きさには上限がある(画面の高さの 1.6%)。ミニチュア倍率を大きくしても、それ以上はぼけない。
- 刈りカスの粒のうち、裏面が見えているものは暗く(黒っぽく)写る。
- 刈りカスの粒は実物より大きい(幅 2.2 cm、長さ 4〜10 cm)。少し離れても見えるようにするため。粒は影を落とさない。
- 地面に残る刈りカスの点々は、今は消えない(芝状態マップの鮮度を使っていて、時間で減らす処理は M7 で入れる)。
- ピントは常に機体に合わせる。地面をクリックして合わせる操作はまだない。
- 真上に近い俯瞰では、画面内の距離の差が小さいので、ミニチュア倍率を上げてもあまりぼけない。
- 自動運転の旋回は、刈る範囲の外(斜面側)に少しはみ出すことがある。旋回の曲線が範囲に収まるかは確かめていない。
- 外周刈りの角と、列の端と外周の間に、小さな刈り残しが出ることがある(テストでの刈れた割合は、四角い範囲で 97% 以上、穴のある範囲で 94% 以上)。
- 外周刈りの経路は、ならした分だけ角が丸くなる(半径 2〜3 m ほど)。入り組んだ境界の細かな出入りは追わない。
- 列をつなぐ順番は「近い順」の単純な方法。入り組んだ形では、離れた列への移動が増える。
- 経路は斜面の向きを考えない。刈る向きは手で決める。
- 斜面用機の区分を刈る機種と経路は未実装(M8)。
- 機体は斜面でも速度が変わらない(重力や滑りは未実装)。
- 車輪の跡は消えない。何度も通った所は跡が重なっていく。芝の再生長(M7)と一緒に、時間で消えるようにする。
- 車輪の跡は、前輪の操舵の向きを見ていない(4 輪とも機体の向きに寝かせる)。
- 芝刈り機のモデルに運転者はいない。色や形は実在の機種に合わせていない。
- 機種を切り替える画面はまだない。使う機種は `vehicle.ts` の `FAIRWAY_MOWER` で固定している。
- 刈り幅は定義から求めるようになり、3.0 m から 3.1 m に変わった(リールどうしの重なりを含む、実際に刈る幅)。経路の列の間隔もその分だけ広がる。
- 山が落とす影はまだない(影を落とすのは機体だけ)。芝の葉も影を落とさない。
- 芝の葉は機体のまわりだけに出る。ドローン視点で機体から離れた所を近くで見ても、そこに葉は出ない。
- 芝の葉は実物より太く(根元 1.8 cm)、まばら(4 cm 間隔)。模型らしさと描画の軽さのための割り切り。
