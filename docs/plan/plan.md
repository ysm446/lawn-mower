# plan — 実装方針と優先順位

更新日時: 2026-11-11 12:27

## 技術構成(案)

- Electron + Three.js(WebGL2)+ TypeScript。ビルドは Vite(electron-vite)。
- テストは Vitest。区分け、経路計画、被覆計算は描画と切り離してテストする。
- 3D アセットは Blender で作り、glTF(.glb)で読み込む。
- Python は使わない見込み。補助スクリプトなどで使う場合は、リポジトリ直下の venv(`.venv`)で実行する。Blender 同梱の Python で動かすスクリプトは対象外。

## 実装方針

- グラフィックは実写寄りで、少しデフォルメの入ったミニチュア風のリアルにする。物理ベースの質感とライティングを土台にし、浅い被写界深度と控えめなデフォルメでミニチュア感を出す。
- 絵の参考はユニクロカレンダー。モデルと地形は実寸(1 単位 = 1 m)で作り、ミニチュア感はカメラ側のミニチュア倍率とティルトで出す。
- タイムラプス表現と芝の再生長は後の段階(M7)で入れる。それまでの実装では、状態マップに鮮度のチャンネルを確保し、シミュレーションを固定時間刻みにしておくことで、後から足せるようにする。
- カメラは物理カメラとして扱う(センサーサイズ、焦点距離、絞り、シャッター速度、ISO)。HDR で描き、露出を掛けてトーンマッピングする。自動露出と被写界深度を持つ。
- 光を現実に近い明るさの単位で扱う仕組みと HDR 描画は、後から入れると調整をやり直すことになるので M1 で入れる。
- 地形はなだらかな起伏のある高さマップ。最初は手続き生成(シード値で再現可能)で作り、後から Blender 製の地形も読めるようにする。
- 刈る範囲は勾配から自動で区分けする。高さマップ → 勾配 → 閾値で分類 → 整形 → 連結領域 → 多角形、という流れで、出力を経路計画の入力にする。
- 芝の状態(高さ、向き、鮮度)は地面に対応する 2D テクスチャで持ち、GPU 上で芝刈り機の刈刃の形を描き込んで更新する。
- 遠景は地面シェーダーで縞を描き、近景だけインスタンシングで芝の葉を描く。
- シミュレーション(車両、区分け、経路、被覆)は描画から分離し、固定時間刻みで進める。
- 自動走行は「経路の生成」と「経路への追従」を分けて作る。
- 見た目の核である「刈り跡の縞」を最初に試作し、成立を確かめてから広げる。

## マイルストーン

M0 から M4 は完了。M5 は物理カメラ(自動露出、被写界深度)と近景の芝の葉まで完了し、空と大気の作り込みが残っている。現在の状況は [progress.md](progress.md) を参照。

| 段階 | 内容 | 完了の目安 |
| --- | --- | --- |
| M0 土台 | Electron + Three.js + TypeScript の雛形。平坦な地面とカメラ | アプリが起動し、地面が表示される |
| M1 刈り跡の試作 | 状態マップ、手動で動く仮の芝刈り機(箱)、地面シェーダーによる縞。HDR 描画、焦点距離指定のカメラ、手動露出とトーンマッピング | 往復して走ると明暗の縞が見える |
| M2 起伏のある地形 | 手続き生成の丘陵、地形に沿う走行、状態マップの地形への投影 | 丘を走って刈り跡が斜面に残る |
| M3 勾配による区分け | 勾配計算、分類、整形、連結領域、多角形化、色分け表示 | 閾値を変えると区分がその場で変わり、妥当な形の領域が得られる |
| M4 自動走行 | 区分けされた領域の往復刈り、Pure Pursuit による追従、経路表示、統計 | ボタン 1 つで刈れる範囲を刈り終える |
| M5 芝の葉と物理カメラ | 近景のインスタンシング芝、影、空と大気、自動露出、被写界深度(オートフォーカス、ミニチュア倍率、ティルト)、カメラ設定パネル | 見下ろすとミニチュア風の実写寄りの絵になり、カメラ設定で写りが変わる |
| M6 芝刈り機 | Blender 製モデル、刈刃の上げ下げ、カメラ各種、早送り | 見た目と操作が一通り揃う |
| M7 時間の表現 | タイムラプス表現(コマ落ち感、太陽と雲の影の変化)、芝の再生長 | 刈る → 伸びる → また刈る、をタイムラプスで眺められる |
| M8 仕上げ | 経路パターンの追加、斜面用の機種、刈りカス、音、保存 | 優先度を見て取捨選択する |

## 優先順位

1. M1 の縞の見え方。ここが弱ければ以降の方針を見直す。
2. 起伏のある地形と勾配による区分け(M2、M3)。このプロジェクト独自の部分。
3. 自動走行と眺める機能。
4. 絵作りとアセットの作り込み。

[concept.md の「未決事項」](../reference/concept.md#11-未決事項)を参照。着手前に決めたいのは次の 3 点。

- 技術構成(Three.js + TypeScript + Vite)でよいか。
- 最初の機種を乗用フェアウェイモアとしてよいか。
- 区分の数と閾値の初期値(案: 15° までを乗用機、30° までを斜面用機、それ以上は刈らない)。
